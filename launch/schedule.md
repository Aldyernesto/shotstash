# Posting schedule

One maintainer has to answer every question, review every first issue and fix what breaks. So the posts are spread over about three weeks, one big audience at a time, with quiet days in between to fix what the previous wave found.

Day 0 is launch day, Wednesday 2026-10-07: v0.3.0 released, images public, demo live, README demo link in (see [checklist.md](checklist.md)). Times are given in US time and in WIB (UTC+7); in October US Eastern is UTC-4 and Pacific is UTC-7.

| Day | Date and time | What | Notes |
| --- | --- | --- | --- |
| 0 | Wednesday 2026-10-07 | Release v0.3.0, demo live, README updated (done) | No posts yet. Watch CI, the demo and the image pulls; check the nightly demo reset the next morning. |
| 1 to 5 | 2026-10-08 to 2026-10-12 | Quiet days | Finish the open owner items in [checklist.md](checklist.md): README test, SM-2 runs, timed fresh install, uptime monitor, last look. |
| 6 | Tuesday 2026-10-13, 08:00 to 10:00 US Eastern (19:00 to 21:00 WIB) | Show HN ([show-hn.md](show-hn.md)) | Clear the next six hours. Answer every comment. |
| 7 to 10 | 2026-10-14 to 2026-10-17 | Fix and reply | Triage issues from HN, ship a patch release if needed, update the docs where people got stuck. |
| 11 | Sunday 2026-10-18, morning US Eastern (evening WIB) | r/selfhosted ([reddit-selfhosted.md](reddit-selfhosted.md)) | Never the same day as Show HN. Check the subreddit rules and flair on the day. |
| 12 to 14 | 2026-10-19 to 2026-10-21 | Fix and reply | Same as above. Note recurring questions for the README and the docs FAQ. |
| 15 | Thursday 2026-10-22, 00:01 Pacific (14:01 WIB) | Product Hunt, optional ([product-hunt.md](product-hunt.md)) | Skip it if the issue queue is still busy. |
| 16 to 21 | 2026-10-23 to 2026-10-28 | Wrap up | Count stars, issues and demo traffic. Write down what to change before the next push. |
| first release + 4 months | Sunday 2027-02-07 or later | awesome-selfhosted pull request ([awesome-selfhosted.md](awesome-selfhosted.md)) | Not earlier: the list requires a first release more than four months old, and the first release (v0.2.0) is from 2026-10-06. |

Rules of thumb:

- If a post takes off, delay the next one rather than stack two spikes.
- If the demo goes down, fix it before answering anything else and say so in the thread.
- Never repost the same text to the same place; a follow-up post needs real news (a release, a new worker).
