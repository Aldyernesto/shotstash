## How it was made

The trailer is built in code, not edited from screen recordings. One deterministic function of time draws every frame with the HTML canvas, and three.js composites the layers on the GPU (motion blur and glow). The UI you see is the real app: the screenshots from this documentation, made from synthetic demo data. The source lives in [`promo/`](https://github.com/%REPO%/tree/main/promo) in the repository, with the frame-exact renderer (`render.mjs`, headless Chrome and ffmpeg) and notes on changing the copy and the timing.
